# AI Habitat

> AI Habitat is an open-source embodied-AI simulation platform from Meta AI Research. It is software you
> install and run locally, not a hosted service: there is no HTTP API, no API key, no base URL and no
> pricing. Two packages carry the platform — habitat-sim, a high-performance C++/Python 3D simulator
> (10,000+ FPS rendering; 8,000+ robot steps/second), and habitat-lab, a modular Python library for
> defining embodied-AI tasks, training agents and benchmarking them. Both are MIT licensed.

IMPORTANT — maintenance status: both READMEs carry a first-party notice stating that "beyond v0.3.4
this project is no longer receiving official active development or maintenance by Meta internal teams"
and inviting the community to fork and continue development independently. v0.3.4 was released
2026-05-07. Treat Habitat as stable-but-unmaintained upstream software when planning an adoption.

Generated by the API Evangelist enrichment pipeline on 2026-08-30 from apis.yml and the artifacts in
this repository. AI Habitat does not publish its own /llms.txt (https://aihabitat.org/llms.txt, 404).

## Install

- Recommended (conda): `conda install habitat-sim withbullet -c conda-forge -c aihabitat`
- Training library: `pip install -e habitat-lab`, then `pip install -e habitat-baselines` for the RL/IL baselines.
- From source: `pip install . --no-build-isolation` — see [BUILD_FROM_SOURCE.md](https://github.com/facebookresearch/habitat-sim/blob/main/BUILD_FROM_SOURCE.md).
- Caution on PyPI: `pip install habitat-sim` resolves to a 0.2.4 dev build from 2023-04-03, three tagged releases behind the source. Use conda or a source build.

## Command line

- `python -m habitat_sim.utils.datasets_download --uids habitat_test_scenes --data-path /path/to/data/` — fetch test scenes.
- `viewer /path/to/scene.glb` — compiled interactive viewer, on PATH after `pip install .`.
- `python examples/viewer.py --dataset data/replica_cad/replicaCAD.scene_dataset_config.json --scene apt_1` — Python viewer.
- `python examples/example.py --scene ...` — non-interactive smoke test.

## Standards this platform speaks

- Gym / Gymnasium environment interface: `import habitat.gym; env = gym.make("HabitatRenderPick-v0")`.
- URDF for robot models (Fetch, Franka, AlienGo).
- glTF/GLB (and .ply) for scene and object assets.
- Bullet for rigid-body and articulated dynamics.
- Hydra/OmegaConf YAML for application configuration.

## What is NOT here

There is no OpenAPI, AsyncAPI, GraphQL SDL, gRPC .proto, WSDL, MCP server, A2A agent card, OAuth scope
set, webhook catalog or error-code registry for AI Habitat, and none is missing by oversight — the
platform has no network protocol surface for any of them to describe. Probes are recorded in
well-known/ai-habitat-well-known.yml and conformance/ai-habitat-conformance.yml.
